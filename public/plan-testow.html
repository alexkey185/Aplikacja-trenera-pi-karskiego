1. Ścieżka nowego testera Bloker

Na świeżym koncie, na telefonie, najlepiej bez patrzenia w swoją wiedzę o aplikacji. Jeśli tu coś jest niejasne — tester nie przejdzie dalej.

  • Rejestracja: formularz akceptuje dane, przycisk działa
  • Mail potwierdzający przychodzi w < 2 min, nie w spamie
  • Link w mailu prowadzi na talentapp.pl (nie localhost:3000)
  • Po kliknięciu linku → /dashboard, widać onboarding
  • Ekran „Nowa drużyna" — zrozumiały, co wpisać
  • Utworzenie drużyny działa, przekierowanie na dashboard
  • Dodanie 3-5 zawodników działa
  • Utworzenie treningu działa
  • Zaznaczenie obecności działa (zielony/czerwony)
  • Po powrocie na /kadra widać 5 kropek
  • Kropki pokazują stan obecności
  • /statystyki pokazuje dane (nie pusty ekran)
  • Wylogowanie działa
  • Ponowne logowanie działa
2. Izolacja danych między kontami Bloker

Dwa konta trenerów (A i B). Konto A ma dane, konto B nie powinno ich widzieć. To najważniejszy test bezpieczeństwa — chodzi o dane dzieci.

  • Konto A: drużyna „Orły" + 3 zawodników + 2 treningi
  • Konto B: drużyna „Lwy" + 2 zawodników
  • Zalogowany jako B: /kadra pokazuje tylko zawodników Lwów
  • Zalogowany jako B: /kalendarz pokazuje tylko treningi Lwów
  • Ręcznie wpisz URL /zawodnicy/[ID_z_Orłów] jako B → 404
  • Ręcznie wpisz URL /druzyny/[ID_Orłów]/edytuj jako B → 404
  • Ręcznie wpisz URL /kalendarz/[ID_treningu_z_Orłów]/obecnosc jako B → 404
  • DevTools Network: zapytania do /rest/v1/ mają filtr druzyna_id=eq.[ID_Lwów]
  • Konto A nadal widzi swoje dane po zalogowaniu
3. Telefony — iPhone i Android Bloker

iPhone (Safari):

  • Rejestracja działa — klawiatura nie zasłania przycisku
  • Mail przyszedł, link działa
  • Logowanie działa — autofill nie psuje pól
  • Wylogowanie działa
  • Reset hasła: link prowadzi na /auth/update-password
  • Instalacja PWA: Udostępnij → Dodaj do ekranu początkowego
  • Po instalacji apka otwiera się bez paska Safari
  • Bottom nav nie skacze (safe-area-inset)

Android (Chrome):

  • Wszystko co wyżej (jak iPhone)
  • PWA install prompt pojawia się po 2 wizytach
  • Po instalacji: ikona na pulpicie, apka fullscreen
  • Autofill ciemny (nie biały)
  • Backdrop-blur nie zamula (FPS w scrollu OK)
4. Prawne minimum Bloker
  • /regulamin — dostępny z /auth/sign-up (link w checkboxie)
  • /regulamin — dostępny z /profil
  • /prywatnosc — dostępny z tych samych miejsc
  • W obu dokumentach brak placeholderów ([ADRES-EMAIL-KONTAKTOWY] zamieniony)
  • Usunięcie drużyny: /druzyny/[id]/edytuj → Strefa niebezpieczna → działa
  • Usunięcie konta: /profil → Strefa niebezpieczna → działa
  • Formularz /profil/pomoc: wysyła zgłoszenie, zapisuje do bazy

Ważne — ale można poprawić po starcie Ważne

Te punkty nie blokują startu. Jeśli coś tu nie działa — zanotuj i popraw w pierwszym tygodniu.

  • Polskie znaki — wpisz „Ćwikła" i wyszukaj „ćwi". Sortowanie alfabetyczne uwzględnia polskie znaki (Ć między B a D).
  • Polskie znaki w PDF — /kalendarz/eksport → sprawdź czy „Ćwikła" wyświetla się poprawnie.
  • Dane skrajne — drużyna z 0 zawodników (pusty stan), z 30 zawodników (wydajność).
  • Długie nazwisko — „Wierzchowskowskа-Nowakowska" — sprawdź czy się nie ucina w złym miejscu.
  • Nowy zawodnik z < 5 treningami — kropki pokazują szare dla brakujących.
  • Kalendarz — powtarzalne — dodaj trening co tydzień na 3 miesiące. Edytuj jedno wystąpienie vs całą serię.
  • Statystyki — okresy — przełącz 30 dni / sezon / cały okres. Sprawdź okres bez treningów.
  • Przeglądarki desktop — Chrome, Edge, Firefox.
  • Słabe łącze — DevTools → Network → Slow 3G. Czy apka nie gubi danych?
  • Brak internetu — wyłącz Wi-Fi. Co widzi user przy próbie zapisu obecności?
Łatwo zapomnieć — sprawdź dziś Ważne
📧 Maile z rejestracji — KRYTYCZNE Wbudowana wysyłka Supabase = 2 maile/godzinę. Przy 3 testerach w jednym dniu trzeci nie dostanie maila.

✅ Sprawdź: Supabase → Project Settings → Auth → SMTP Settings → czy „Enable Custom SMTP" jest ON (powinno być smtp.resend.com).
✅ Test: zarejestruj 3 konta w ciągu 5 minut. Wszystkie 3 maile dochodzą?
⏸️ Supabase pausing Free tier pauzuje projekt po 7 dniach nieaktywności. Pierwszy request po pauzie = 5 min opóźnienia.

✅ Rozwiązanie: UptimeRobot (darmowy) ping na /api/health co godzinę. Albo Vercel Cron.
💾 Backupy Free tier = 7 dni retencji automatycznych backupów. Dla danych dzieci rozważ:
✅ Tygodniowy ręczny pg_dump
✅ Albo Daily backup do S3 (wymaga konfiguracji)

✅ Cloudflare Email Routing → kontakt@talentapp.pl → forward do Gmaila (5 min konfiguracji)
